# java-lotto-precourse

## 개요

간단한 로또 발매기를 구현한다.

---

## 기능 목록

- 입력
- [ ]  로또 구입 금액 입력 (1000원으로 나누어 떨어지지 않는 경우 예외처리)
- [ ]  당첨 번호 입력 (쉼표 기준으로 분리)
- [ ]  보너스 번호 입력

- 실행
- [ ]  구입 금액 입력에 해당 하는 로또 수량 계산
- [ ]  해당 로또 수량만큼 로또 발행
- [ ]  중복 없이 6개 숫자 선택 후 저장
- [ ]  발행한 로또와 당첨 번호 비교
- [ ]  당첨 내역 저장
- [ ]  등수별 금액 계산
- [ ]  수익률 계산
- [ ]  예외 상황 시 에러 메시지 출력 후 입력 재개

- 출력
- [ ]  구입 금액 입력 메시지 출력 (”구입금액을 입력해 주세요.”)
- [ ]  발행한 로또 수량 출력 (숫자 + “개를 구매했습니다.”)
- [ ]  로또 번호 출력 (오름차순 정렬)
- [ ]  당첨 번호 입력 메시지 출력 (”당첨 번호를 입력해 주세요.”)
- [ ]  보너스 번호 입력 메시지 출력 (”보너스 번호를 입력해 주세요.”)
- [ ]  당첨 내역 출력(당첨 통계, 일치한 개수 당 금액, 당첨 장 수, 수익률)
- [ ]  수익률 출력 (소수점 둘째 자리에서 반올림)
- [ ]  예외 상황 시 에러 문구 출력 (에러 문구는 [ERROR]로 시작)

---

## 예외 처리

- [ ]  구입 금액이 1000원으로 나누어 떨어지지 않는 경우
- [ ]  당첨 번호가 1에서 45 사이의 숫자가 아닌 경우
- [ ]  당첨 번호 입력 시 쉼표가 아닌 다른 문자를 사용하였을 경우
- [ ]  당첨 번호가 6개의 숫자가 아닌 경우
- [ ]  보너스 번호가 1에서 45 사이의 숫자가 아닌 경우
